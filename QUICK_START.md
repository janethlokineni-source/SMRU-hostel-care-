## 🔧 **OPTIONAL: Production Setup (10 minutes total)**

### **📧 Email Notifications (5 minutes)**
1. **Go to [emailjs.com](https://emailjs.com)** - Create free account
2. **Add Gmail service** - Connect your email
3. **Create template** - Copy from NOTIFICATION_SETUP.md
4. **Get 3 IDs** - Service, Template, User ID
5. **Update `notification-service.js`** - Lines 35-39

### **🗄️ Database Backend (5 minutes)**
1. **Go to [supabase.com](https://supabase.com)** - Create free project
2. **SQL Editor** - Paste contents of `supabase_schema.sql`
3. **Run SQL** - Creates all tables
4. **Settings > API** - Copy URL and Key
5. **Update `supabase-config.js`** - Lines 11-12
